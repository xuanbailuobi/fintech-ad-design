# 数据反馈驱动的新图制作

适用：已有金融广告素材及投放反馈，需要分析原因、提出方案或制作改进版本。
这里沉淀的是分析和制作方法；没有回传结果的新版仍是待测试假设。

## 先建立素材与数据对应

优先用素材名、编号、缩略图和投放日期交叉定位。截图不清楚时先读取原尺寸，只把能确认的数值录入；缺失、截断和空白标为未知，不能当零。
记录数据来源、日期、市场、人群、版位、优化目标、归因窗口、币种及各阶段事件定义；已知资料直接复用，只询问会影响结论的缺口。
区分全账户、筛选后合计与当前选中的素材。不同日期或人群的比较只能作为方向参考，不能自动当作同条件实验。

平台与归因工具的数据不可混用。先核对 CTR/CPC 使用全部点击、链接点击还是其他定义；注册、授信、申请、放款也按报表实际事件命名，不擅自替换。
如果报表本身混合来源，可以复算并称为“报表比率”，但不能声称它追踪了同一批用户的完整转化。

## 逐环节读数

贷款素材常用链路：曝光 → 点击 → 下载/安装 → 注册 → 申请/授信 → 放款。按产品真实链路增减阶段。

| 指标 | 在相同且兼容口径下的计算 |
|---|---|
| CTR | 点击 ÷ 曝光 |
| CPM / CPC | 消耗 ÷ 曝光 × 1,000 / 消耗 ÷ 点击 |
| 阶段转化率 | 下一阶段人数 ÷ 上一阶段人数 |
| 阶段获客成本 | 消耗 ÷ 该阶段人数 |
| 每千次点击的放款数 | 放款人数 ÷ 点击数 × 1,000 |

分母为零或缺失时标为不可计算。加总比较使用总分子 ÷ 总分母，不平均各素材百分比；由人数复算，再与显示四舍五入的值校对。
除比率外一起看人数和消耗。小样本、转化延迟、未完整结束的归因期要影响结论强度，不设置脱离业务的固定“合格线”。

## 从现象到可测试假设

每张素材分别给出：已观察到的事实 → 可能的创意原因 → 非创意解释/需核查项 → 修改和验证方式。
不能把相关性写成因果，也不能据素材额度推断某类借款人的资质。

| 观察到的现象 | 可检查的画面与文案 | 同时需要排除的因素 |
|---|---|---|
| 点击低，点击后转化较好 | 主金额是否显眼、标题是否泛、对比度和阅读负担 | 受众、版位、频次、出价与曝光成本 |
| 点击高，安装低 | 吸引点是否误解、CTA是否明确、广告与商店页是否一致 | 误触、商店加载、下载条件、跟踪差异 |
| 安装后注册低 | 广告中的申请预期是否与实际流程一致 | 登录/权限/表单故障、操作系统和网络 |
| 注册后授信低 | 是否吸引了与产品条件不匹配的申请需求 | 风控策略、申请完成率、拒绝原因 |
| 授信后放款低 | 到账额、总成本、期限是否与广告预期一致 | 实际授信额度、支付故障、等待时间与到期转化 |
| 后段转化较好，获客成本高 | 是否优先修复前段表达并保留有效诉求 | 样本量、竞价、市场成本与归因延迟 |

标题夸张、金额不清、过多留白等只能作为待验证的创意解释；不要因为某个比率下降就保证换图能修复。
先按用户目标选择主指标。贷款获客通常同时看放款成本和放款量；下载或注册目标则按当前投放目标评价。放款率不等于信用质量、利润或长期回收表现，没有相应数据不能推断。

## 形成逐图方案

每张新版只围绕一个主要改进假设，保留原图已有证据支持的有效机制，不把所有素材统一成同一种模板。

项目内记录：
- 原素材编号、数据区间和主要流失环节。
- 观察事实、原因假设及尚缺的证据。
- 保留项与改动项；产品参数是否改变。
- 新图编号、目标画板、主观察指标及需要守住的其他环节。
- 状态：待测试 / 已回传 / 支持假设 / 不支持 / 证据不足。

若用户要求“先分析、给方案再作图”，在方案阶段交付并等待用户继续；用户已明确授权分析后执行时，不增加无必要的确认关卡。
将需要用户决策的产品事实与可自主处理的布局选择分开；不因非关键缺口阻止独立工作。

## 制作改进版

依照主假设调整信息层级、金额、对比机制、步骤和CTA。可以改变构图，但要保留与原素材的对应关系。
复用已确认的地区、语言和产品参数；重新核算利率、期限、总利息、总支付及费用范围。月利息不能称为月还款，只有还款安排明确时才展示月付。
先修正事实或算术错误，不能为了控制变量而继续发布错误表达。若修正了产品参数，同时记录这是一个额外变化。
不把“必批”“固定时间到账”等原广告主张自动继承到当前产品。

默认在用户指定的空白区域创建可编辑新版，保留原素材供比较；按用户要求的尺寸和工具交付。
在画板外附简短测试说明，广告内部只保留消费者需要的信息，不加入内部诊断、编号或测试指标。
依照作图规范验收实际截图。版面完成只代表设计交付完成，不代表投放效果已经得到验证。

## 回传与学习

尽量同日期、人群、版位、优化目标和归因口径对照；如存在差异，写明限制。
改动一个元素有利于定位效果；如果同时改了多项，只能评价整个版本，不能声称已识别某个元素的单独作用。
CTR下降但最终成本改善、放款增加，可能仍是更有效的版本；反过来也一样，必须按预先确定的业务目标判断。
回传结果支持哪一条假设就更新哪一条；无结果不宣称提升，不把一次结果升为所有国家和APP的规律。

## 发布边界

通用技能只收录方法和匿名/构造示例。投放截图、精确消耗、账户标识、素材与Figma定位信息留在项目记录，不随通用公开仓库发布。
仅制作设计或提供测试方案不等于授权投放、调整预算、上传客户数据或更改账户设置。
