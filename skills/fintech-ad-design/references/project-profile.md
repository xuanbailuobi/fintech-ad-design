# 项目资料

每个品牌、地区或产品版本独立记录；可以在用户指定的项目文件中维护。
不要把真实项目参数直接写进全局技能。首次使用只询问资料中缺失且会影响结果的内容。

## 最小项目简表

| 字段 | 需要记录的内容 |
|---|---|
| 产品 / APP | 产品名、项目ID、Logo来源 |
| 国家 / 地区 | 实际投放市场 |
| 广告语言 | 语言及地区变体；不能仅由国家推断 |
| 币种 | ISO代码、展示符号、数字分隔格式 |
| 借款范围 | 产品范围与本批广告选用范围分别记录 |
| 借款周期 | 数值或范围、天/月/年单位 |
| 利率 | 数值、日/月/年/每期单位、适用条件 |
| 计息方式 | 原始本金平息、剩余本金或明确的自定义规则 |
| 还款安排 | 先息后本、先本后息、本息分期或自定义支付计划 |
| 制作要求 | 参考图、尺寸、交付文件、可编辑范围 |

有分期或费用展示时再确认：
- 期数、频率、各期本金/利息、尾款和舍入规则。
- 计息起止日与天数约定。
- 费用、扣费时点、实际到账金额。
- 对比基准、相同本金与期限、是否包含费用。

## 信息状态

每条关键事实记录来源、确认日期、适用范围和状态：
已确认 / 待确认 / 已失效。
未知费用不是零。缺失期限不是默认180天。
新项目不能自动使用旧项目的币种、0.04%利率或金额范围。

## 其他资料

记录文案分类、原文与页码、改写版本、已核实主张、素材来源、Figma画板和受保护图层。
用户隐藏或保留的单图修改是项目特例，不是通用设计要求。
私有项目数据可放在本仓库已忽略的 private-projects/ 中；
需要跨设备同步时使用用户认可的私有渠道，不默认推送到公开仓库。
